OTA 设备接口

设备使用 Bearer Token 和 X-Device-ID 鉴权，检查更新时同时提交当前版本与通道。

GET/v1/ota/check
GET/v1/ota/firmware/{release_id}.bin
curl /v1/ota/check \
  -H "Authorization: Bearer DEVICE_TOKEN" \
  -H "X-Device-ID: szp-001" \
  -H "X-Firmware-Version: 1.0.0" \
  -H "X-OTA-Channel: stable"
